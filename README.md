## 📌 Overview

**Shopping Behaviour Intelligence** transforms customer transaction data into actionable insights through data analytics, machine learning, and interactive visualizations.

The platform helps analyze:

* Customer demographics
* Purchase behaviour
* Product performance
* Revenue patterns
* Customer value
* High-value customer segments
